نبذة عني

طالب جامعي مجتهد في السنة الثانية بكلية الهندسة المعلوماتية. أطور مواقع ويب عصرية وتفاعلية باستخدام JavaScript، وإطار عمل Bootstrap. أعتمد على Webpack لتحسين أداء التطبيقات. أنجزت عددًا من المشروعات التدريبية بكفاءة وأطمح للعمل مع فريق برمجي لتعزيز تطوري المهني، وتطبيق مهاراتي التقنية للمساهمة في نجاح مشاريع الشركة.

التفاصيل التقنية

تطوير واجهات المستخدم

أتقن بناء وتنسيق المواقع باستخدام HTML و CSS و JavaScript. أستخدم Flexbox لتنظيم العناصر وتوزيعها، وأجيد العمل مع المتغيرات والدوال في JavaScript لإنشاء وظائف تفاعلية. أستفيد من مكتبة jQuery للتفاعل مع DOM. نفذت عدة مشاريع تدريبية منها موقع إلكتروني لمدرسة ابتدائية، ومدونة شخصية باستخدام Hugo، تتضمن عدة صفحات بمحتوى مرن قابل للتحديث.

Bootstrap

أجيد استخدام Bootstrap لتصميم واجهات متجاوبة باستخدام Grid System، لضمان التكيف مع مختلف الأجهزة والشاشات. طورت موقع مشابه لموقع YouTube وآخر لشركة، مع تخصيص CSS وSass لتجاوب الصفحات عبر media queries وكذلك حسنت توافق الموقع مع معايير SEO. بنيت 5 صفحات هبوط متجاوبة منها صفحة شخصية Portfolio تتضمن خط زمني للمهارات المكتسبة.

Webpack

أعتمد على Webpack لإعداد بيئة العمل وتنظيم المشاريع باستخدام npm وNode.js. أحسن الأداء عبر التقسيم التلقائي، الضغط، والتصغير للملفات. طورت متجر إلكتروني لبيع الملابس ولوحة تحكم طبقت بها منهجية BEM وهيكلية ITCSS لتحسين هيكلة الكود.

التكامل مع الواجهات البرمجية API

قادر على التكامل مع APIs لجلب البيانات وعرضها بشكل ديناميكي باستخدام AJAX وFetch API. طورت موقع إخباري يعرض الأخبار باستخدام Open API وSwagger، مع استخدام Web Components وتحويل التواريخ باستخدام Moment.js.
